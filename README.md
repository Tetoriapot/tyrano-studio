# Tyrano Studio

[ブラウザで使う](https://tetoriapot.github.io/tyrano-studio/)

日本語のティラノスクリプト制作補助ツールです。インストール不要で、タグ辞典（126件）、レシピ（25件）、選択肢、レイアウト、タイトル、CG・おまけの6モードを使えます。

## 使い方

1. 上部からモードを選びます。
2. 文字・画像・位置を編集します。画像はPNG・JPEG・WebPに対応しています。
3. 「保存済み」を確認します。配置と画像は、このブラウザに自動保存されます。
4. 必要な生成コードをコピーします。

右上の「ヘルプ」で詳しい使い方と保存の説明、「更新履歴」で変更内容を確認できます。開いた案内は「閉じる」またはEscで閉じられます。

画像の処理と編集データの保存はブラウザ内で行います。画像や編集データをサーバーへ送る機能、ログイン、アクセス解析はありません。GitHub Pagesへのページ取得の通信は発生します。

## 保存と対応状況

- 保存は同じブラウザ・同じサイトの中だけで有効です。ローカル版や別の端末のデータは自動移行されません。
- ブラウザのサイトデータ削除で保存内容も消えます。ZIP入出力・プロジェクト管理・端末間同期は提供していません。
- デスクトップ版Chromeで確認しています。スマートフォンでの編集や他ブラウザは未検証です。
- 現在は開発版です。生成コード・辞典・レシピのティラノ実機検証は未完了で、確認エンジン版は **UNVERIFIED** です。参照した公式V6リファレンスと実機確認済みの版は区別しています。
- CGのページ送り・解放条件のゲーム内連携、画面入退場の後片付け、LOAD帰還などは今後の検証・実装対象です。エディタで条件式を実行しません。
